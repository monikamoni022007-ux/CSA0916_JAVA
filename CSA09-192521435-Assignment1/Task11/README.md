# Task 11 — Integrated System, Testing and Defence

The demo runs the same integrated acceptance checks used by Task 12. It covers entry/exit, vehicle rates, monthly passes, duplicate and invalid operations, full capacity, invalid vehicle category, EV charging and manual daily collection.

From the project root, compile as described in the root README, then run:

```powershell
java -cp out task11.SmartParkingSystemDemo
```
