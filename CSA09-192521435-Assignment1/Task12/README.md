# Task 12 — Day-4 Design Challenge

The demo exercises configurable e-bike flat pricing, delivery-van peak-window boundaries and partial overlaps, visitor pass validity, and five unequal-capacity floors. The e-bike amount must be supplied from the course rule; the tests use an explicitly labelled fixture amount rather than claiming an official rate.

From the project root, compile as described in the root README, then run:

```powershell
java -cp out task12.Day4DesignChallenge
```
