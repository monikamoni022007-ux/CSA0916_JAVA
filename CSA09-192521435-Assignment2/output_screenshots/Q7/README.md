# Q7 screenshot capture guide

Run the Q7 compile and execution commands from the project root. Capture the real VS Code
terminal after the comparison has completed.

| Recommended filename | Capture |
|---|---|
| `Q7_equivalence_and_timing.png` | Output-equivalence confirmation, both averages, computed reduction, objective status, checksum confirmation, and timing CSV path. |
| `Q7_heap_sample_caveat.png` | Both approximate retained-heap deltas and the warning that one post-GC sample does not establish a memory improvement. |

Save only manually captured screenshots in this folder. This guide is not execution
evidence.
