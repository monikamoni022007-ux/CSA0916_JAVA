# Q4 screenshot capture guide

Run the Q4 compile and execution commands from the project root. Capture the real VS Code
terminal after report-order checks and benchmark completion.

| Recommended filename | Capture |
|---|---|
| `Q4_order_validation.png` | The report-order verification messages for each approach and all three inventory sizes. |
| `Q4_benchmark_summary.png` | The measured benchmark table, warm-up/repetition counts, and CSV path. Use consecutive part filenames if needed to keep values legible. |

Save only manually captured screenshots in this folder. This guide is not execution
evidence.
