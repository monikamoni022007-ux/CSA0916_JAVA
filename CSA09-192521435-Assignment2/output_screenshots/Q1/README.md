# Q1 screenshot capture guide

Run the Q1 compile and execution commands from the project root. Capture the real VS Code
terminal after the program completes; do not edit, synthesize, or crop away the command
or output context.

| Recommended filename | Capture |
|---|---|
| `Q1_run_latest.png` | The Java command, `StringJoiner` and `String.format` examples, timing-summary lines for the workloads, equivalence confirmation, and CSV output paths. If one image cannot show all of this legibly, use `Q1_run_latest_part1.png` and `Q1_run_latest_part2.png`. |

An earlier screenshot named `Q1_run.png.jpeg` is present, but its timings predate the
latest CSV run. Capture the latest run separately so the image agrees with the current
CSV. Save only genuine terminal screenshots in this folder; this guide is not execution
evidence.
