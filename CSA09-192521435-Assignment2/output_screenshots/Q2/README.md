# Q2 screenshot capture guide

Run the Q2 compile and execution commands from the project root. Capture the real VS Code
terminal after the program completes; benchmark timings are run-specific.

| Recommended filename | Capture |
|---|---|
| `Q2_run_latest_part1.png` | The Java command, Up Next demonstration, validation message, and size-1,000 measurements. |
| `Q2_run_latest_part2.png` | The size-10,000 measurements and the beginning of the size-50,000 measurements. |
| `Q2_run_latest_part3.png` | The rest of the size-50,000 measurements, warm-up/repetition counts, and CSV path. |

Three older images (`Q2_run_1.png.jpeg` through `Q2_run_3.png.jpeg`) are present. They
show an earlier run, so their timings do not match the latest CSV; capture the current run
separately. Save only genuine terminal screenshots in this folder. This guide is not
execution evidence.
