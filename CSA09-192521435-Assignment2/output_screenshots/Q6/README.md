# Q6 screenshot capture guide

Run both Q6 Java commands from the project root. Capture the real VS Code terminal; timing
values depend on the machine and run.

| Recommended filename | Capture |
|---|---|
| `Q6_supplied_triage_order.png` | The exact six-patient order printed by `Triage`. |
| `Q6_eight_patient_validation.png` | The eight-patient order, correctness message, and results CSV path. |
| `Q6_benchmark_summary.png` | The measured queue-operation table, warm-up/repetition counts, and benchmark CSV path. Use consecutive part filenames if needed. |

Save only manually captured screenshots in this folder. This guide is not execution
evidence.
